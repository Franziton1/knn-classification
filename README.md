# \## 🚀 Project Overview

# \* \*\*Dataset:\*\* 4 continuous numerical features (`x1`–`x4`) with a binary target label (`class`).

# \* \*\*Preprocessing:\*\* Mean imputation for missing values and feature standardization (`StandardScaler`) for distance-metric optimization.

# \* \*\*Evaluation:\*\* Train-test split, 5-fold cross-validation, confusion matrix analysis, and classification reports.

# 

# \## 📂 Repository Contents

# \* `knn.py`: The core Python script containing the full machine learning pipeline and inference logic.

# \* `data\_knn.txt`: The input dataset used for training and testing.

# \* `knn\_technical\_report.pdf`: A professional technical report detailing the workflow, visualizations, and performance metrics.
